# 泊松足球实验室

手机优先的足球概率分析原型。服务端读取懂球帝公开联赛页面，自动完成球队选择、三层攻防加权、联赛基准计算和泊松概率输出。

## 已实现

- 联赛与主客队自动选择，无需手工填写进失球。
- 主队历史主场、客队历史客场权重 50%；两队全部联赛比赛 40%；最近 3 场同联赛比赛 10%。
- 每层按 5 场先验强度向相应联赛均值收缩，降低小样本噪声。
- 从联赛完整赛程计算主场、客场真实进球均值，不设置主观主场加成。
- 输出预期进球、胜平负、大小球、双方进球、零封和最可能比分。
- 页面展示每层样本量、收缩后的进失球和 λ 代入过程。
- 公开页面缓存 30 分钟、并发限制和每秒请求间隔。
- 7 项解析与模型单元测试。

## 模型

设联赛场均主队进球为 μH、客队进球为 μA。主队合成进攻为 GFH，客队合成失球为 GAA，则：

```text
λ主 = GFH × GAA ÷ μH
λ客 = GFA × GAH ÷ μA
```

每个比分 P(h,a) 使用两个独立泊松概率的乘积。比分矩阵动态扩展，覆盖率至少接近 99.9%。

## 本地运行

```bash
pip install -r requirements.txt
playwright install chromium
uvicorn app:app --host 0.0.0.0 --port 8000
```

如果系统已有 Chromium，可设置：

```bash
CHROMIUM_EXECUTABLE=/path/to/chromium uvicorn app:app
```

手机与电脑连接同一网络后，访问电脑的局域网地址和端口；公网使用需部署 Docker 服务。

## 云端部署

项目包含 `Dockerfile` 和 `render.yaml`，可部署到支持 Docker 的 Render 等服务。部署后必须分别测试球队列表和完整分析接口，不能仅凭网页打开就认定抓取成功。

## 已核验限制

- 2026-11-22：当前云主机直接请求及无头浏览器请求懂球帝公开页返回 HTTP 567，真实浏览器人工访问可读。这是源站访问控制/网络环境限制，当前版本不会绕过验证。
- 雷速官网在当前环境返回 HTTP 405；球探/新球体育候选页面连接超时，因此第一版未接入。
- 不同部署网络的结果可能不同，正式使用前必须重新验证；源站改版也需要维护解析器。
- 独立泊松未修正低比分相关性，也未纳入阵容、红牌、战意和赛程密度。
- 50/40/10 与 5 场先验均为待历史回测参数，不代表已证明最优。
- 仅用于数据研究，概率不是确定赛果或投注建议。
