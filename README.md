# 老杨足球实验室

手机优先的足球概率分析工具。GitHub Actions 定时读取 football-data.co.uk 的真实比赛结果、每日赛程和亚盘盘口，GitHub Pages 提供免费手机页面。当前覆盖 30 个欧洲、亚洲和美洲主流联赛，首页按当天赛程自动生成比赛列表，无需手动选队。

## 当前版本

- 支持 30 个联赛、545 支当前赛季球队：原 11 个顶级联赛，新增英冠、西乙、意乙、德乙、法乙，以及瑞典超、瑞士超、日本J1、奥超、俄超、挪超、巴甲、阿甲、波超、丹超、芬超、罗甲、墨超、美职联。仅使用各赛事当前赛季已结束比赛，球队显示中文名并保留原始英文队名。
- 首页按北京时间自动生成当天比赛列表，不再要求手动选择联赛和球队。
- 每场显示两队预期进球、预期总进球、大小 2.5 球概率、胜平负预测和最可能比分。
- 主赛程同步采集 `AHh` 主队让球线、Bet365 主/客亚盘赔率及市场平均赔率，显示真实采集时间；ESPN 补充赛程没有亚盘字段时明确留空。
- 对比模型净胜球差（λ主−λ客）与盘口基准（−AHh），差值达到 ±0.15 球才显示模型倾向，否则显示方向不明；不输出投注金额或收益承诺。
- 赛前预测写入档案后不再覆盖，盘口仅在开球前更新快照并保留变化历史。
- GitHub Actions 每 6 小时更新并重新发布；数据源失败时工作流失败，不编造或用空数据替代。
- 每日赛程批量预测：主赛程文件与 ESPN 每日接口合计覆盖 29 个联赛，统一转换为北京时间；波超因暂无可用赛程接口只做历史回测。
- 8 种模型同场比较：联赛均值基准、当前 50/40/10、稳健主客场、近期状态增强、近 5 场状态、2/10 场先验及 Dixon–Coles 低比分修正。
- 赛前预测写入 `data/prediction_archive.json` 后不再覆盖，赛后只回写真实比分；首次读取时已开赛的比赛不补造预测、不计成绩。
- 每场历史回测只使用该场之前的赛果，展示胜平负命中率、三分类 Brier 和 Log Loss；先比 Log Loss，再比 Brier，命中率辅助。
- 26 项当前数据与预测测试，覆盖解析、中文译名、数据生成、预测冻结、亚盘读取、盘口方向与赛前快照；页面另做实数据浏览器核验。

## 模型

设联赛场均主队进球为 μH、客队进球为 μA。主队合成进攻为 GFH，客队合成失球为 GAA，则：

```text
λ主 = GFH × GAA ÷ μH
λ客 = GFA × GAH ÷ μA
```

每个比分 P(h,a) 使用两个独立泊松概率的乘积。比分矩阵动态扩展，页面显示实际概率覆盖率。

## 每日预测、赛后核对与最优模型

`predictions.html` 读取 `data/predictions.json`，提供当天全部赛程、8 模型预测、实际比分、命中状态和模型排行榜。`prediction_pipeline.py` 负责：

1. 读取主赛程 `fixtures.csv` 与 ESPN `scoreboard`，按北京时间筛选当天比赛。
2. 开球前将各模型预测冻结到 `data/prediction_archive.json`；档案已存在时不覆盖预测或锁定时间。
3. 赛果到达后按联赛、主客队和临近日期回写实际比分。
4. 对当前赛季逐场滚动回测，预测第 i 场只传入 `rows[:i]`，每联赛先积累至少 30 场。
5. 统计命中率、三分类 Brier 和 Log Loss，分别输出全联赛与各联赛排行，并单独统计上线后的真实赛前档案成绩。

“当前最优”是现有样本下的相对结果，不是未来保证；历史回测与真实赛前跟踪分开显示。

## 静态页面与自动更新

`index.html` 是当天赛程、泊松指标与亚盘对比入口；`predictions.html` 是 8 模型预测、赛后核对与回测入口，两者都读取 `data/predictions.json`。`generate_data.py` 和 `prediction_pipeline.py` 仅使用 Python 标准库下载、校验并生成真实数据。

```bash
python3 generate_data.py
python3 prediction_pipeline.py
python3 -m unittest test_generate_data test_prediction_pipeline -v
```

`.github/workflows/deploy-pages.yml` 每 6 小时及手动触发时重新抓数、运行测试、冻结赛前预测、回写赛果并部署 Pages；仅将预测档案提交回仓库，发布工作流不因普通 push 自动运行。仓库 Pages 的 Source 必须选 **GitHub Actions**。

## 旧 FastAPI 原型

`app.py`、`scraper.py` 和 `server.html` 保留懂球帝公开页面版本，用于后续维护或数据源对照；它不是当前 GitHub Pages 版本的数据通路。

```bash
pip install -r requirements.txt
playwright install chromium
uvicorn app:app --host 0.0.0.0 --port 8000
```

## 数据来源与已核验限制

- 当前公开版赛果数据源：https://www.football-data.co.uk/ 。主联赛赛季 CSV 路径形如 `mmz4281/2627/E0.csv`，全场进球使用 `FTHG` / `FTAG`；扩展联赛使用 `new/SWE.csv` 等文件，按 `Season` 和 `Country` 严格过滤，全场进球使用 `HG` / `AG`。未来比赛、空比分、历史赛季及国家不匹配的文件不会纳入赛果。
- 每日赛程来自 `https://www.football-data.co.uk/fixtures.csv` 和 ESPN 公共 `scoreboard`。主赛程时间按源站英国时间解析，ESPN 使用 UTC，页面统一转北京时间。主赛程的 `AHh` 是主队让球线（负数为主队让球、正数为主队受让），`B365AHH/B365AHA` 是 Bet365 主/客赔率，`AvgAHH/AvgAHA` 是市场平均赔率；只使用源站赛前字段，不把赛后 `AHCh`  closing 字段冒充赛前盘口。波超 `pol.1` 当前返回 HTTP 400，故仅波超没有每日预测，仍有历史回测；其他源读取失败会在页面标为失败，不伪造空赛程。
- 用户本轮另要求的韩国K1、保超、捷甲、克甲、斯洛伐克超、哥伦甲、沙特联、摩洛哥超暂未接入：当前数据源没有对应的可靠文件。实测 `KOR.csv` 实际为挪威数据、`COL.csv` 实际为波兰数据，已明确禁止用其冒充。
- 2026-11-22：当前云主机与 GitHub Actions 请求懂球帝公开页均返回 HTTP 567，因此公开版改用可读取的真实 CSV，不宣称仍在自动抓取懂球帝。
- 雷速官网在当前环境返回 HTTP 405；球探/新球体育候选页面连接超时，未接入。
- 源站字段、赛程或访问规则改变时需要维护；工作流只保证按公开源生成，不保证第三方服务永久可用。
- 独立泊松未修正低比分相关性，也未纳入阵容、红牌、战意和赛程密度。
- 50/40/10 与 5 场先验均为待历史回测参数，不代表已证明最优。
- 仅用于数据研究，概率不是确定赛果或投注建议。
